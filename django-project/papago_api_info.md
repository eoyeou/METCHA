# Papago API 제한 정보

## 무료 플랜 제한

### 텍스트 번역 API
- **한 번에 최대**: 5,000자
- **하루 최대**: 10,000자
- **초당 요청**: 최대 10개

### 유료 플랜
- 네이버 클라우드 플랫폼에서 유료 플랜 제공
- 더 많은 할당량 사용 가능

## 대량 번역 시 권장사항

1. **googletrans 사용** (무료, 제한 적음)
   - 하루 약 15,000자 가능
   - 제한이 있지만 Papago보다 여유 있음

2. **Papago API 사용 시**
   - 하루 10,000자 제한 고려
   - 중요한 리뷰만 선별하여 번역
   - 여러 날에 나눠서 번역

3. **Google Translate API** (유료)
   - 월 50만자 무료 후 과금
   - 대량 번역에 적합

## API 키 발급 방법

1. 네이버 개발자 센터 접속: https://developers.naver.com/
2. 애플리케이션 등록
3. Papago 번역 API 선택
4. Client ID와 Client Secret 발급
