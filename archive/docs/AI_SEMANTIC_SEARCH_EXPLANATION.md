# AI 의미 기반 검색 시스템 설명

## 개요

**"Sentence Transformers + ChromaDB, 기능 : 자연어 검색"** 이는 프로젝트에서 AI가 사용된 핵심 부분으로, 사용자가 자연스러운 언어로 검색할 수 있는 의미 기반 검색 시스템을 의미합니다.

## 기술 스택

### 1. Sentence Transformers (AI 모델)

**역할**: 텍스트를 벡터(임베딩)로 변환하는 AI 모델

**사용 모델**: `BAAI/bge-m3`
- 1024차원 벡터 생성
- 다국어 지원 (한국어 포함)
- 문장의 의미를 벡터로 표현

**사용 위치**:
- `reviews/embedding_utils.py`
- 검색어와 리뷰 텍스트를 모두 임베딩으로 변환

**예시**:
```python
# 사용자가 입력한 검색어
query = "혼자 보기 좋은 영화"

# Sentence Transformers가 이를 1024차원 벡터로 변환
query_embedding = embed_text(query)
# 결과: [0.023, -0.145, 0.789, ..., 0.234] (1024개 숫자)
```

### 2. ChromaDB (벡터 데이터베이스)

**역할**: 임베딩 벡터를 저장하고 유사도 검색을 수행하는 벡터 데이터베이스

**특징**:
- 리뷰들의 임베딩을 미리 저장
- 검색어 임베딩과 유사한 리뷰를 빠르게 찾음
- 코사인 거리나 L2 거리로 유사도 계산

**사용 위치**:
- `reviews/chroma_utils.py`
- 모든 리뷰의 임베딩이 사전에 저장됨

**동작 과정**:
```python
# 1. 모든 리뷰가 이미 ChromaDB에 임베딩으로 저장되어 있음
# 2. 검색어 임베딩으로 유사한 리뷰 검색
similar_reviews = search_similar_reviews(
    query_embedding=query_embedding,
    n_results=100
)
# 결과: 검색어와 의미가 유사한 리뷰들을 거리 순으로 반환
```

### 3. 자연어 검색 (Natural Language Search)

**의미**: 사용자가 키워드가 아닌 자연스러운 문장으로 검색할 수 있는 기능

**전통적인 키워드 검색 vs 의미 기반 검색**:

| 방식 | 예시 검색어 | 동작 방식 | 결과 |
|------|------------|----------|------|
| **키워드 검색** | "매트릭스" | 정확히 "매트릭스"라는 단어가 포함된 리뷰만 찾음 | 제한적, 오타나 다른 표현 못 찾음 |
| **의미 기반 검색** | "혼자 보기 좋은 영화" | 문장의 의미를 이해하여 관련 리뷰 찾음 | 유연함, 의도 파악 가능 |

**실제 동작 예시**:

1. **사용자 입력**: "비오는 날 보기 좋은 영화"
   - 키워드 검색: "비오는", "날", "보기", "좋은", "영화" 각각 검색 → 정확도 낮음
   - 의미 검색: 문장 전체의 의미를 파악 → 관련 영화 찾음

2. **사용자 입력**: "웃기면서도 감동적인 영화"
   - 키워드 검색: "웃기면서도", "감동적인" 정확히 포함된 리뷰만 찾음
   - 의미 검색: "유머러스하면서 감동적인", "웃음과 감동이 있는" 등 유사 표현도 찾음

## 전체 프로세스

### 1단계: 데이터 준비 (사전 작업)
```
모든 리뷰 텍스트 
  → Sentence Transformers로 임베딩 변환
  → ChromaDB에 저장
```

### 2단계: 검색 실행 (실시간)
```
사용자 검색어 입력
  ↓
Sentence Transformers로 검색어 임베딩 변환
  ↓
ChromaDB에서 유사한 리뷰 검색 (벡터 유사도 계산)
  ↓
리뷰 → 영화 매핑
  ↓
점수 계산 및 정렬 (유사도 + 사용자 취향)
  ↓
검색 결과 반환
```

### 3단계: 결과 반환
- 검색어와 의미가 유사한 리뷰가 있는 영화들을 순위대로 반환
- 단순 키워드 매칭이 아닌 의미적 유사도 기반

## 코드 흐름

```python
# movies/search_views.py의 semantic_search 함수

# 1. 검색어 임베딩 변환 (Sentence Transformers)
query_embedding = embed_text(query)  # AI 사용!

# 2. ChromaDB에서 유사 리뷰 검색 (벡터 유사도 검색)
similar_reviews = search_similar_reviews(
    query_embedding=query_embedding,
    n_results=100
)  # AI 사용!

# 3. 리뷰 → 영화 매핑 및 점수 계산
# 4. 최종 검색 결과 반환
```

## 왜 AI인가?

### 전통적인 방법 (AI 없음)
- 키워드 매칭: 정확히 같은 단어만 찾음
- 정규표현식: 패턴 매칭만 가능
- **한계**: 의미 이해 불가, 동의어/유사 표현 인식 못함

### AI 기반 방법 (현재 시스템)
- **의미 이해**: 문장 전체의 의미를 벡터로 표현
- **유사도 계산**: 벡터 간 거리로 의미 유사도 측정
- **유연성**: 비슷한 의미라면 다른 표현도 찾을 수 있음

## 예시 시나리오

**사용자 검색**: "힐링되는 영화"

1. **Sentence Transformers**가 "힐링되는 영화"를 벡터로 변환
   - 벡터는 "평화로운", "위로", "감정 치유", "편안한" 등의 의미를 내포

2. **ChromaDB**에서 유사한 리뷰 검색
   - "마음을 편안하게 해주는 영화" 리뷰 → 높은 유사도
   - "스트레스 풀리는 영화" 리뷰 → 높은 유사도
   - "따뜻하고 감동적인 영화" 리뷰 → 중간 유사도
   - "액션 블록버스터" 리뷰 → 낮은 유사도

3. 결과로 유사도가 높은 영화들을 순위대로 반환

## 요약

**"Sentence Transformers + ChromaDB, 기능 : 자연어 검색"** 의미:

- **ChromaDB**: 벡터를 저장하고 유사도 검색을 수행하는 데이터베이스
- **자연어 검색**: 사용자가 자연스러운 문장으로 검색할 수 있는 기능

→ **결과**: 키워드가 아닌 **의미 기반**으로 영화를 검색할 수 있는 시스템
