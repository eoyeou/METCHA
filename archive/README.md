# Archive 폴더

이 폴더는 프로젝트 개발 과정에서 생성된 설명 문서 및 임시 파일들을 보관하는 곳입니다.

## 폴더 구조

### `docs/`
프로젝트 설명 및 분석 문서들

**django-project에서 이동:**
- `AI_SEMANTIC_SEARCH_EXPLANATION.md` - AI 의미 검색 시스템 설명 문서
- `SEARCH_DUPLICATE_REMOVAL_ANALYSIS.md` - 검색 중복 제거 로직 분석 문서
- `SEARCH_IMPLEMENTATION.md` - 검색 시스템 구현 가이드

**프로젝트 루트에서 이동:**
- `HEAVINESS_SATISFACTION_EXPLANATION.md` - Heaviness/Satisfaction 지표 설명
- `SIMILAR_MOVIES_SCENARIO.md` - 유사 영화 추천 시나리오 설명
- `PPT_TECH_DIFFERENTIATION.md` - PPT 기술 차별성 문서
- `PROJECT_SETUP_GUIDE.md` - 프로젝트 세팅 가이드

**참고**: 핵심 내용은 프로젝트 루트의 `README.md`와 `ARCHITECTURE.md`에 통합되어 있습니다.

### `scripts/`
임시 스크립트 파일들 (필요시 추가)

---

## 주요 문서 위치

프로젝트에서 실제로 사용하는 핵심 문서:

- **README.md** - 프로젝트 전체 README (필수)
- **ARCHITECTURE.md** - 시스템 아키텍처 문서 (필수)
- **PPT_CONTENT.md** - PPT 슬라이드 내용 (프레젠테이션용)

---

## 참고사항

이 폴더의 문서들은 개발 과정에서 참고용으로 생성된 문서들입니다. 프로젝트 실행에는 필수적이지 않으며, 핵심 내용은 위의 주요 문서들에 통합되어 있습니다.

필요시 이 폴더의 문서들을 참고하여 내용을 확인할 수 있습니다.
